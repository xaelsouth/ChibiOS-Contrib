FG23-BRD2600A (REV A03) radio board with EFR32FG23B010F512IM48
================================================================

The BRD2600A is the radio board of the FG23 DK2600A dev kit (EFR32FG23
868-915 MHz +14 dBm, 512 kB flash, 48-pin QFN). This board file targets
board revision A03 as found on DK2600A kits.

Board features used by the demos:
  - LED0 on PB2, BTN0 on PB1, BTN1 (escape hatch) on PA5
  - J-Link VCOM (EUSART) on PA9=TX / PA10=RX
